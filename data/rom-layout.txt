# How tools/disasm.py splits ROM rev R into source files.
# ADDR<TAB>NAME<TAB>DESCRIPTION. A region runs to the next entry; its start
# moves forward to the next whole object or instruction. Regions longer than
# about #3000 nibbles are split further, each file named by its start address.
# Upper-ROM library parts get regions of their own automatically.
# Descriptions of lower-ROM regions are inferred from the entry-point names
# found there (EDB/VBL); refine them as the code is understood.
00000	hardware	Reset and interrupt entries, keyboard, timers, low-level system code
02000	rpl-core	Object prologs, the RPL inner loop and stack primitives
04000	bints	Built-in binary integers and stack words
06000	rpl-control	EVAL, COLA, ?SKIP and other control words
08000	memory	Directories, variables and memory management
0A000	misc-0A000
0C000	time	Clock and alarms
0E000	units	Unit objects and conversion
10000	units-grob	Unit arithmetic and graphics objects
12000	graphics	Display buffers and graphics
14000	decompile	Decompiling and displaying objects
16000	strings	Conversion of objects to strings
18000	dispatch	Argument checks and type dispatch
1A000	user-arith	User arithmetic commands (x+, x*, ...)
1C000	user-commands	User commands
22000	programs	Program structures and library 700
24000	parser	Parser and compiler
2A000	reals	Real number arithmetic
2C000	misc-2C000
2E000	io	Serial I/O and Kermit
30000	io-print	I/O and printing
34000	arrays	Arrays
36000	long-reals	Extended real arithmetic
38000	display	Status area and annunciators
3A000	menus	Menus and the built-in libraries 0A1-0A7
3E000	keys	Key handling
40000	outer-loop	Parameterized outer loop and menus
42000	input	Key input and the cursor
44000	editor	Command line editor
46000	plot	Plotting
52000	flags	System and user flags
54000	algebra	Symbolic algebra
60000	rpl-utils	Control structures and stack utilities
66000	misc-66000
70000	libraries	Library table, access pointers, bank switching
74000	messages	Message tables
76000	hash	Hash table of library 002
78000	misc-78000
7A2B3	fonts	System fonts (10-row, 8-row, minifont) and the minifont remap table
7C855	misc-7C855
7E000	version	Fill and version strings
80000	selftest	Self-test code (runs with RAM unconfigured)
